# Art requests for Radbro Tiny Wizard

Keep each candidate in a Radclaw run with source references and permissions.
Keep technical results separate from art release approval.
Use the current public Radcat and Quiver art until a replacement pack is approved.
Do not add private paperdoll files to a public template or web export.

## Compare these directions

1. Native 64 by 64 Radbro pixel art with a restrained dungeon palette.
2. The published Radcat style with a matching illustrated dungeon and enemies.
3. Radbro character art with a hand-drawn Quiver-style environment.

Use the same room composition, enemy count, camera, and light level for every comparison.
Show a still image and a moving engine proof for each candidate.
Do not select a final style from a still image alone.

## First batch

| Asset | Required proof |
| --- | --- |
| Player | Idle and walk. Keep the native grid, timing, floor anchor, and identity. |
| Modular outfit | Keep one shared frame clock, layer order, hide rules, and complete-stack mirroring. |
| Enemy | Idle, travel, contact, hurt, and death. Test visibility against the floor. |
| Projectile | Visible at gameplay scale. Show normal and upgraded forms. |
| Room | Floor, four wall sides, four corner types, and an open/closed north door. |
| Pickups | Heart, key, and weapon upgrade. Keep silhouettes distinct. |
| Effects | Hit flash, impact, death, pickup, and exit feedback. |
| UI | Health, wave state, key status, pause, restart, and touch controls. |

A single mirrored view is a valid first style test.
Do not call it four-direction art.
If the art needs four views, request front, rear, left, and right explicitly.
Keep aiming separate from the character body where possible.

## Review sheet

For each candidate, record source reference, creator/tool, source hash,
permission, editable source path, runtime export path, native size,
anchor, frame durations, rig revision, and review status.
Compare identity, motion, clarity, environment fit, editability, and file size.
Ask the user to select the direction after the playable comparison is ready.
